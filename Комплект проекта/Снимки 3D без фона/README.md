# Снимки 3D-моделей САПР-001 без фона

167 изображений PNG с прозрачностью. Имена файлов, разрешение и ракурсы совпадают с [галереей на тёмном фоне](../Снимки%203D/README.md). Кадры получены в OpenCAD Studio 2026.47. Альфа-канал восстановлен по двум рендерам каждого ракурса на однотонных фонах.

После доработки F1 и жгутов заново экспортированы 52 кадра. Обновлены держатель, жгуты, вентилятор M1, три сборки и виды контроллера без крышки.
