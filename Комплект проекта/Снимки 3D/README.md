# Снимки 3D-моделей САПР-001

167 изображений PNG из 16 исходных DWG и дополнительных видов отдельных деталей. Состав DWG зафиксирован в таблице ниже. Базовая ревизия проекта `c3b0eac`. Для демонстрационной сборки использована локальная версия на момент съёмки. Виды получены из затенённой области OpenCAD Studio 2026.47 через MCP. PNG кадрированы по границам объектов, элементы интерфейса скрыты.

Для каждого DWG есть изометрия и шесть ортогональных видов. Названия «Спереди», «Справа» и другие соответствуют направлениям мировой системы координат в OpenCAD Studio. Для деталей и сборок, где это помогает увидеть обратную сторону, добавлена изометрия с противоположного угла.
