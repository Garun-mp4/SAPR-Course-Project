# Чертежи контроллера вентиляции САПР-001

Комплект включает четыре листа сборочного чертежа версии 05, два чертежа деталей, принципиальную схему, перечень элементов и спецификацию. [Результаты сверки с моделями](Сверка%20с%203D.md) содержат измерения, источники и условия сборки.

[3D-модели деталей и сборок для OpenCAD Studio](Редактируемые/3D/README.md) включают корпус с внутренним монтажом, внешний вентилятор и разнесённую сборку.

[Снимки 3D-моделей](../Снимки%203D/README.md) включают изометрии, ортогональные виды и отдельные изображения деталей.

Редактируемый DWG с шестью 2D-листами содержит линии, окружности и текст в пространстве модели. У каждого листа свой слой. Геометрия дана в масштабе листа; при измерении в DWG учитывайте масштаб соответствующего вида. Рабочие файлы выпуска находятся в [hardware](../../hardware) и [outputs](../../outputs). Для печати используйте PDF с масштабом 100%.
